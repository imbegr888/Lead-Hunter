# 🎯 Multi-Source Lead Hunter Bot

Автоматизированный комплекс на Python для многоканального поиска клиентов и коммерческих заказов (разработка ботов, парсеров, веб-интерфейсов). Проект спроектирован по модульной архитектуре с использованием современных асинхронных библиотек.

## 🛠 Технологии и стек
* **Python 3.10+**
* **Aiohttp & Selectolax** (высокопроизводительный асинхронный веб-парсер и аудитор)
* **Telethon** (интеграция с Telegram API для мониторинга чатов в реальном времени)
* **Aiogram 3** (асинхронная отправка мгновенных алертов в личный бот)

## 📂 Модули системы
1. **Site Analyzer (`site_analyzer.py`)** — сканирует сайты компаний, выявляет технические проблемы (отсутствие HTTPS, устаревший стек, недоступность хоста).
2. **Job Parser (`job_parser.py`)** — собирает свежие IT-вакансии и заказы по ключевым словам.
3. **Telegram Monitor (`tg_monitor.py`)** — слушает профессиональные чаты фриланса через Userbot на предмет горячих заявок.
